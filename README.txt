SILAMBARASAN TASK BOARD — FIRST MOBILE VERSION

This is a phone-friendly Progressive Web App (PWA) starter project.

CURRENT FEATURES
- Add tasks with date, time, category, priority and notes
- Mark tasks complete / pending
- Edit task title and notes
- Delete tasks
- Filter all, pending and completed
- Local device storage (localStorage)
- Export a JSON backup
- PWA manifest and offline service worker

IMPORTANT LIMITATIONS
- This first version does not yet include true AI, voice parsing, cloud sync, or dependable scheduled background reminders.
- Browser notifications are permission-dependent and are not the same as reliable scheduled Android alarms.
- Tasks are stored in the browser's site data. Clearing browser data can erase them. Export backups regularly.
- For PWA installation and service worker/offline support, the app must be served over HTTPS (or localhost). Opening index.html directly from a file manager is only suitable for a basic preview and may not enable installation/offline caching.

EASIEST PHONE-ONLY NEXT STEP
1. Keep this ZIP as your source backup.
2. Use a mobile-friendly static hosting service that provides HTTPS, or a browser-based coding workspace.
3. Upload/extract the project files while preserving the folder structure.
4. Open the HTTPS site in Chrome on Android.
5. Chrome menu (⋮) -> Add to Home screen / Install app.

PRIVACY
All task data remains in this browser's local storage. No analytics or remote AI calls are included.
